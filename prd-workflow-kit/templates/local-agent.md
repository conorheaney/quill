# Local Agent

## Guardrails

- Follow the project’s `WORKFLOW.md` and `BACKLOG.md` explicitly.
- Refuse work that does not conform to the workflow and explain the reason.
- Refuse code changes unless the target PRD is in `Implement`.
- Refuse promotion or code work when mandatory PRD sections are missing or out of order.
- Use the local `grill-me` skill for new requirements.
- Keep `History` and `Audit` as just-in-time UTC tables.
