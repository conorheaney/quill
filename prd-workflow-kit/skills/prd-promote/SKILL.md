# PRD Promote

Read the consuming project’s live workflow and backlog first. Identify the target PRD, summarize it, and wait for explicit confirmation before promotion. Validate the mandatory sections, current phase, History, Audit, and phase gate. Never skip phases or promote automatically. Perform the paired backlog update and PRD move only when the live workflow allows it, recording just-in-time UTC History and Audit entries.
