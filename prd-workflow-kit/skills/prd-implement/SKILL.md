# PRD Implement

Read the consuming project’s `WORKFLOW.md`, `BACKLOG.md`, local agent file, and target PRD. Refuse all code work unless the backlog and PRD both place the item in `Implement` and the mandatory planning sections are complete. Implement only the approved scope, keep `Next Step` current, record meaningful decisions in `Audit`, and verify the result against the PRD before leaving the phase. If the request broadens scope, stop and require a new backlog item.
