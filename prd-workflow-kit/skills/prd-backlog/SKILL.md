# PRD Backlog

Read the consuming project’s `WORKFLOW.md`, `BACKLOG.md`, local agent file, and `grill-me` skill before acting. Use `grill-me` to shape the requirement, then create one six-digit PRD entry and matching file in the configured Backlog folder. Follow the project’s mandatory section order, add the initial `Backlog` History row immediately, and keep the backlog and file aligned. Refuse the request if the live workflow or required skill is unavailable.
