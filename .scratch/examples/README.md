# Markdown Examples

This folder is a compact set of editable markdown examples for verification work.

The set is intentionally small so it stays useful in day-to-day testing without becoming cluttered.

## Recommended Use

- Start with the first two files if you want natural prose-heavy reading samples.
- Use the later files when you want richer markdown structures for rendering, editing, and edge-case checks.

## Selection Notes

- The first two files are clean prose-heavy examples.
- The last four files are the strongest renderer-checking examples in the set.
- Everything in this folder is safe to open, edit, duplicate, or break during testing.
