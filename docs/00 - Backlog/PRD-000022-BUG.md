# PRD-000022-BUG

## Short Name

Fix Minimal Document Render Layout

## Goal

Keep the Render pane full-height and its content top-aligned for new and minimal documents.

## Context

When a new file is started or a short file is loaded, the rendered area can appear vertically centred instead of filling the available space below its header.

## Scope

In:

- new and loaded documents with minimal content
- Render pane height and top alignment
- preserve scrolling for longer documents

Out:

- Markdown rendering or typography changes
- pane resizing or unrelated layout work

## Plan

- Reproduce the layout, identify its CSS owner, and plan the smallest full-height fix.

## Acceptance Criteria

- New and minimal documents render from the top of a pane that fills the available vertical space.
- Longer documents still scroll normally.

## Verification

- Compare new, minimal, and long documents in the packaged desktop app at representative window sizes.

## Next Step

Move to `01 - Plan`, reproduce the layout, and identify the responsible container and CSS rules.
