# PRD-000043-UI

## Short Name

Refine Theme Token System

## Goal

Create a more cohesive and contemporary visual language for Quill by refining the palette and semantic theme tokens used across the application while preserving the identity of the Light, Dark, Sepia, and Nord themes.

## Context

The current themes have clear identities, but their surfaces, borders, accents, transparency, elevation, and focus treatments are not yet organized as a small semantic system. A more deliberate palette and token hierarchy could make the editor feel sleeker, calmer, and more consistent as additional themed surfaces are addressed by PRD-000042-UI.

## Scope

In:

- Define semantic roles for base, raised, overlay, subtle, border, text, muted text, accent, status, focus, and selection colors.
- Refine the Light, Dark, Sepia, and Nord palettes while preserving their distinct visual character.
- Establish a restrained elevation, radius, transparency, and motion vocabulary where it improves visual cohesion.
- Verify contrast, focus visibility, hierarchy, and consistency across the built-in themes.

Out:

- Replacing the theme selector or adding new themes.
- Redesigning application layout, typography, or component behavior.
- Implementing the dialog, popup, toast, and highlighted-area coverage owned by PRD-000042-UI.
- Reintroducing gradients or changing user-authored content styling.

## Plan

During planning, inventory the existing theme tokens and component usage, map them to a compact semantic role system, compare candidate palette values across all four themes, and define measurable contrast and visual-hierarchy checks before implementation is authorized.

## Acceptance Criteria

- AC-01: The four built-in themes use a documented semantic palette and elevation vocabulary that preserves theme identity, improves visual consistency, and maintains readable contrast and visible focus states.
