# PRD-000042-UI

## Short Name

Extend Theme Surface Colors

## Goal

Make Quill's dialogs, popup borders, toasts, and highlighted areas follow the selected theme so the application presents a cohesive and current visual system.

## Context

The theme-gradient cleanup establishes a simpler visual foundation, but several application surfaces still need explicit theme-aware color treatment. Inconsistent dialog, popup, toast, and highlighted-area colors can make the selected theme feel incomplete and weaken hierarchy or readability. This item depends on PRD-000043-UI, which defines the semantic theme-token foundation these surfaces will consume.

## Scope

In:

- Review dialog backgrounds, borders, text, and action states against the selected theme.
- Review popup and menu borders and supporting surface colors.
- Review toast backgrounds, borders, text, and status variants.
- Review highlighted, active, and selected areas that should use theme-consistent colors.
- Verify contrast, hierarchy, and theme updates across every available built-in theme.

Out:

- Changing theme names, theme selection behavior, typography, layout, or unrelated component structure.
- Adding new themes or changing user-authored content styling.
- Reintroducing or changing gradient treatments covered by PRD-000041-UI.

## Plan

After PRD-000043-UI establishes the semantic palette, inventory the affected dialog, popup, toast, and highlight selectors, map them to the agreed theme tokens, and define visual and contrast checks for each built-in theme.

## Acceptance Criteria

- AC-01: Dialogs, popup borders, toasts, and highlighted areas use colors that follow the selected built-in theme while preserving readable contrast and clear visual hierarchy.
