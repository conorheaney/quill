# PRD-000040-UI

## Short Name

Replace Tauri Chrome With HTML Title Bar

## Goal

Replace Quill's current Tauri/native window chrome with a custom HTML title bar that preserves the current window title and provides minimize, restore, and close controls in a slightly taller bar.

## Context

The current desktop window uses Tauri's existing window chrome. The requested shell change is to make this chrome part of Quill's HTML UI while retaining the essential window actions and current title. The target height should be slightly greater than the existing window chrome so the visual treatment remains deliberate and usable.

## Scope

In:

- Investigate the current Tauri window-chrome configuration and desktop window-command path.
- Define an HTML title bar containing the current title, minimize, restore, and close controls.
- Define the target height relative to the existing window chrome and the required visual, interaction, keyboard, and accessibility behavior.
- Verify that window actions continue to operate correctly in the packaged desktop runtime.

Out:

    - Adding tabs, menus, extra window actions, or unrelated shell redesign.
- Changing the document title source or other application window behavior beyond what is required for the custom title bar.

## Plan

Implement the custom chrome as an isolated window module and narrow desktop bridge. Use a fixed 40 px title bar in an explicit shell layout row, preserve window resizing, and reserve a draggable region whose controls are excluded. Use `Quill Markdown Editor` as the shared static title, delegate unsaved-close confirmation to the document/session flow, reuse existing theme tokens, and support standard Windows double-click maximize/restore behavior. Verify the packaged Windows application at 100% scaling across all available themes before acceptance.

## Acceptance Criteria

- AC-01: The custom HTML title bar displays `Quill Markdown Editor` and only the requested minimize, maximize/restore, and close controls.
- AC-02: The title bar is fixed at 40 px and is measurably slightly greater than the current packaged Windows chrome at 100% scaling.
- AC-03: Minimize, maximize/restore, title-bar double-click, and close operate reliably, with close delegating unsaved-change confirmation to the existing document/session flow.
- AC-04: The title bar follows the selected Quill theme using existing theme tokens, including readable hover, active, and keyboard-focus states across all available themes.
- AC-05: The title bar preserves window dragging, edge resizing, keyboard access, accessible names, and usable editor layout height in the packaged Windows application.
