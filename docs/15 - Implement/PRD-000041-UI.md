# PRD-000041-UI

## Short Name

Remove Theme Gradients

## Goal

Remove dated gradient treatments from Quill's built-in themes and replace them with a cleaner, more contemporary visual treatment without reducing theme distinction or readability.

## Context

Quill currently uses gradients in theme backgrounds and shared visual surfaces. These treatments make the application look dated and should be reviewed as one coherent theme change across all built-in themes.

## Scope

In:

- Audit gradient declarations used by the built-in themes and shared theme-owned surfaces.
- Define solid, theme-consistent replacements that preserve contrast, hierarchy, and visual distinction.
- Verify the updated appearance across every available built-in theme.

Out:

- Changing the theme names, theme selector behavior, typography, layout, or unrelated visual styling.
- Removing gradients from user-authored content or functional image rendering.

## Plan

During planning, inventory all theme-related gradient declarations, decide the replacement token or color for each surface, and define visual and contrast checks for every built-in theme before implementation is authorized.

## Acceptance Criteria

- AC-01: All built-in Quill themes present the affected application surfaces without gradients, while retaining readable contrast and clear visual distinction between themes.
