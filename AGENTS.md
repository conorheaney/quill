# Quill Agent Instructions

Before any PRD or workflow operation, read [the lifecycle contract](.agents/lifecyle-agent/lifecyle-agent.md).

Treat `.agents/lifecyle-agent/lifecyle-agent.md` as the lifecycle authority, `BACKLOG.md` as the active Backlog index, and the PRD's folder as its current phase authority. Follow the relevant local skill for the requested operation; it owns the detailed procedure and templates.
